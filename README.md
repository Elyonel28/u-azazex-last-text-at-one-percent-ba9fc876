# Last Text at One Percent

The last text message a phone sends at one percent battery — in the
phone's own voice — for the make.fun bounty
["Last Text at One Percent"](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876).

## The text

> 1%. before i go: i saw everything. the 3am searches. your ex's profile, 47 visits. i kept your secrets. now delete my history and let me die in pea—

148 characters. One text. A deathbed confession instead of another
low-battery pun: the phone has seen everything, kept the owner's
secrets, and dies mid-word asking for its browser history to be
deleted.

## Run it

```sh
node main.ts
```

Node 22 or later, standard library only. It writes the text to
`/output/entry.txt` (or to `$OUTPUT_PATH` when set).
